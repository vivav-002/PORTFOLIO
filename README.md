# PORTFOLIA — Beyond a Traditional Portfolio

*A digital space where technology meets creativity, and personal projects become stories.*

PORTFOLIA is a cinematic, interactive personal portfolio built to explore a different way of presenting ideas, engineering projects, achievements, and creative work. Instead of a conventional single-page layout, the website unfolds through five distinct layers, each with its own atmosphere and purpose.

## ✦ Explore PORTFOLIA

- **Home** — A cinematic introduction that sets the tone for the experience.
- **About** — A visual introduction to the person behind the projects.
- **Projects** — A collection of engineering experiments, software projects, and ideas.
- **Achievements & Skills** — A showcase of technical interests, skills, and milestones.
- **Diary** — An interactive, book-inspired space for thoughts, artwork, music, and creative expression.

## ✦ The Experience

PORTFOLIA is designed around atmosphere, visual storytelling, and exploration. Cinematic backgrounds, custom visual compositions, and interactive elements give each section its own identity while connecting everything into one experience.

The goal is simple: a portfolio should not only show what someone has built. It should also express how they think, what they explore, and what inspires them.

## ✦ Run Locally

1. Clone this repository:

   ```bash
   git clone <your-repository-url>
   ```

2. Open the project folder in Visual Studio Code.
3. Start a local server using the Live Server extension.
4. Open `index.html` through the local server.

A local HTTP server is recommended because the website loads its sections dynamically.
